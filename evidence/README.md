# Investigation Evidence

This directory contains supporting evidence collected during the SOC Detection & Investigation Lab.

The evidence documents the investigation workflow performed using Splunk Enterprise and Microsoft Sysmon telemetry from the Windows 11 lab endpoint.

Evidence includes:

- Sysmon telemetry validation
- Suspicious process execution
- Parent-child process relationships
- PowerShell and command-line activity
- System and network discovery
- DNS and network activity
- Event correlation and timeline reconstruction

All activity was generated within an isolated cybersecurity lab environment for defensive security training and portfolio demonstration.
