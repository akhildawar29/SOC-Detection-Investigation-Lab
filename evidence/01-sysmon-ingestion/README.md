# Sysmon Telemetry & Ingestion Validation

## Purpose

This section documents the validation of Microsoft Sysmon telemetry and confirms that endpoint security events from the Windows 11 lab system were successfully ingested and searchable within Splunk Enterprise.

Before conducting the incident investigation, telemetry availability was verified to ensure that relevant endpoint activity could be reconstructed reliably.

## Data Source

- **Endpoint:** Windows 11 Cyber Lab
- **Telemetry:** Microsoft Sysmon
- **SIEM:** Splunk Enterprise
- **Primary Log Source:** Microsoft-Windows-Sysmon/Operational

## Validation Approach

Splunk searches were used to confirm the presence and consistency of Sysmon events generated by the monitored endpoint.

The validation established that the dataset contained telemetry required for subsequent investigation, including:

- Process creation events
- Command-line execution data
- Parent-child process relationships
- DNS query activity
- Network connection activity
- Supporting endpoint events

## Investigation Relevance

Validating telemetry before beginning detailed analysis reduces the risk of drawing conclusions from incomplete event data.

The confirmed Sysmon dataset provided the foundation for process-chain reconstruction, PowerShell analysis, network investigation, event correlation, and MITRE ATT&CK mapping performed later in the investigation.

> **Analyst Note:** Telemetry validation was treated as the first investigative control to establish confidence in the available evidence before suspicious activity was analysed.
